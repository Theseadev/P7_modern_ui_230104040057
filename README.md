# P7_modern_ui_230104040057

## 📦 Deskripsi

P7_modern_ui_230104040057 adalah proyek Android (Kotlin) yang berfokus
pada **Modern UI**.\
Proyek ini menggunakan struktur standar Android --- termasuk file
Gradle, konfigurasi, dan modul `app`. Tujuan utamanya adalah menyediakan
basis UI modern sebagai starting point aplikasi Android.
